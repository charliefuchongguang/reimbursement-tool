# 需求收集文档

> 状态：✅ 已确认

## 需求概述
一款面向**招标代理公司出差人员**的**报销自查与归档辅助工具**。在提交报销前，由出差人员自己使用，帮助 TA 录入各类报销凭证、自动校验是否符合公司报销规范、按规则归档整理发票，减少人工核对和返工。

> **使用对象：** 出差人员本人（非财务/非审批用途）
> **使用时机：** 提交正式报销单之前的自查与整理

## 核心功能

### F1. 指定发票来源文件夹
- 用户在工具中**指定一个本地文件夹**，里面放着该次出差的全部发票（PDF + XML 混杂）
- 支持批量读取文件夹下的所有发票文件

### F2. 自动识别发票内容
- 解析 **XML 发票**（最准确，结构化数据直接读取）
- 解析 **文本型 PDF 发票**（直接抽取 PDF 内嵌文字）
- ⚠️ **特例：火车票仅 PDF，无 XML**，识别逻辑必须兼容（不能因为缺 XML 就报错）
- ⚠️ **不支持**扫描件/图片型 PDF（这类发票需用户手动补录金额）
- 识别字段：发票号码、开票日期、金额（含税/不含税/税额）、发票类型（专票/普票/电子普票/火车票/行程单）、销售方、备注栏内容、**出发地/目的地/航班/车次/乘客**等
- **AI 辅助处理**（DeepSeek API）：
  - 字段清洗与归一化（统一日期、金额格式）
  - 自动判断该发票属于 9 类报销中的哪一类（交通/打车/住宿/餐饮…）
  - 备注栏关键信息抽取（机票乘机人/航班号、住宿人/入离时间、火车票出发到达车站等）
  - 异常识别（专票/普票判定、特殊场景提示）

### F3. 自动分类归档
- 按公司归档规则建立**根文件夹**：`报销人 + 报销金额 + 项目简写`
- 根文件夹下按 9 类分子文件夹（如 `01_交通费/`、`02_打车费/` …）
- 每张发票的 PDF + XML 一起搬到对应类别下
- ⚠️ **特殊处理**：打车费的**滴滴/出租车行程单**单独建一个子文件夹（如 `02_打车费/行程单/`）
- ⚠️ **特殊处理**：交通费的火车票仅 PDF，按 PDF 单独归档即可

### F3.5. 交通费链路校验
- 把所有"交通费"类发票按时间排序
- **首张**的出发地应为**北京**
- **末张**的到达地应为**北京**
- ✅ **允许多城市连续行程**（如 北京→上海→杭州→北京），中间段不强制校验衔接
- 如果首尾任一不是北京，**提醒用户"是否缺失交通发票"**

### F5. 合规性自查（必做）
依据公司报销规范，对识别出的发票自动检查并给出问题清单：

| 检查项 | 规则 |
|---|---|
| **机票发票** | 备注栏须包含：①乘机人姓名 ②行程（出发地+目的地）③乘机时间 ④航班号 — 缺一项即提示 |
| **住宿费发票** | 备注栏须包含：①住宿人姓名 ②入离时间；并校验**附件中是否有"住宿水单/账单明细"**对应文件，缺则提醒 |
| **电子发票完整性** | 除火车票外，每张 PDF 必须配套 XML，缺则提示补 |
| **专票适用性** | 餐饮费/礼品费/替票之外的类别，若开成普票则提示「建议改开专票」 |
| **专家评审费** | 提示用户「公司转账的需贴专家签名表」 |
| **预付卡发票** | 识别到则警告「预付卡发票会被代扣 20% 个税，建议避免」 |
| **替票** | 识别到不规范类别时提示「需另附说明表备注实际费用」 |

输出形式：在网页右侧/下方展示"问题清单"，每条可定位到具体发票文件，方便用户去补办或修改。

### F4. 生成报销单（填好金额）
- **强制要求**：必须套用公司**差旅费报销单**模板 [notes/新差旅费报销单-2025-11-14.xlsx](file:///d:/AI/11%E3%80%81%E5%85%AC%E5%8F%B8%E5%86%85%E9%83%A8%E9%A1%B9%E7%9B%AE/%E8%87%AA%E5%8A%A8%E6%8A%A5%E9%94%80%E5%B7%A5%E5%85%B7/notes/%E6%96%B0%E5%B7%AE%E6%97%85%E8%B4%B9%E6%8A%A5%E9%94%80%E5%8D%95-2025-11-14.xlsx)，不得改变格式
- 按 9 类报销自动汇总金额，填入模板对应单元格
- 输出可直接打印/提交的 Excel 文件

## 报销类别支持
共 **9 类**：

| 序号 | 类别 | 说明 |
|---|---|---|
| 1 | **交通费** | 往返北京 ↔ 出差地的**火车票 / 机票**（不含打车）<br/>⚠️ 火车票仅 PDF，无 XML<br/>⚠️ 链路校验：按时间排序，**起点和终点应均为北京**，否则提示是否缺票 |
| 2 | 打车费 | 出差期间的市内出行；除 PDF+XML 外，**还有行程单**（行程单单独存一个文件夹） |
| 3 | 住宿费 | 出差住宿（备注栏需注明住宿人/入离时间，附水单） |
| 4 | 复印装订费 | |
| 5 | 专家评审费 | 公司转账的需贴专家签名表 |
| 6 | 办公用品费 | |
| 7 | 餐饮费 | 通常普票即可 |
| 8 | 会议室费用 | |
| 9 | 快递费 | |

## 使用方式
**网页应用（多用户版，可部署到云服务器）** —— 浏览器中打开即可使用。

- 用户通过**手机号 + 密码登录**后使用（注册时自定义密码）
- 用户**指定本地发票文件夹**（通过浏览器文件选择器）
- 识别结果与归档输出落到本地磁盘
- 调用大模型时经**自有后端代理**，仅传送**发票文本内容**，不上传原始发票文件
- 大模型 API Key 由**管理员统一配置**，用户无需自行填写
- 后续若有需要，可打包成桌面壳（如 Electron/Tauri）二次分发

## 条件与限制
（草稿，公司报销规范摘要）

| 项 | 要求 |
|---|---|
| 报销单模板 | **必须套用** [新差旅费报销单-2025-11-14.xlsx](file:///d:/AI/11%E3%80%81%E5%85%AC%E5%8F%B8%E5%86%85%E9%83%A8%E9%A1%B9%E7%9B%AE/%E8%87%AA%E5%8A%A8%E6%8A%A5%E9%94%80%E5%B7%A5%E5%85%B7/notes/%E6%96%B0%E5%B7%AE%E6%97%85%E8%B4%B9%E6%8A%A5%E9%94%80%E5%8D%95-2025-11-14.xlsx)，不得自定义格式 |
| 专票要求 | 除餐饮费、礼品费、替票外，尽量开专票（可抵税），需打印两张 |
| 电子发票 | 必须同时提供 PDF + XML 格式原件 |
| 机票发票 | 备注栏须注明：乘机人、行程、时间、航班号 |
| 住宿费发票 | 备注栏须注明：住宿人、入离时间，并附住宿水单 |
| 专家费 | 公司转账的需贴专家签名表 |
| 替票处理 | 按实际发票种类填写，另附说明表备注实际费用 |
| 归档规则 | 文件夹命名：`报销人+报销金额+项目简写` |
| 备注用笔 | 发票上备注用铅笔，不用签字笔 |
| 预付卡发票 | 尽量避免（会额外代扣 20% 个税） |
| 大额礼品 | 不报销的不要开公司抬头发票（防税务预警） |

## AI 相关
- **是否需要 AI 功能**：✅ 是
- **AI 服务提供商**：**DeepSeek**（[https://platform.deepseek.com](https://platform.deepseek.com)）
- **用途**：发票字段清洗、报销类别自动归类、备注栏关键信息抽取、合规规则判定
- **API Key 管理**：
  - ⚠️ **严禁硬编码** API Key 到代码中
  - 由**管理员**在「设置」中统一配置，保存在**服务端**数据库，**不下发前端**
  - 普通用户设置弹窗不显示 Key 项
  - 调用大模型经后端 `POST /api/ai/chat` 代理，仅传送**发票文本内容**，不传送原始 PDF/XML 文件
