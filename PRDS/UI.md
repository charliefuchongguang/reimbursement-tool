# UI 设计文档

> 项目：招标代理公司出差报销辅助工具（Reimbursement Helper）
> 状态：✅ 已确认

---

## 一、整体风格

- **风格**：极简卡片式，单页面 + 步骤条引导
- **主色调**：白底 + 蓝色强调色（`#1890FF` / Element Plus 默认主蓝）
- **字体风格**：系统默认（PingFang SC / 微软雅黑）
- **设计目标**：信息密度高（要展示多张发票），但操作流程清晰（步骤条引导一步步走）

---

## 三、交互设计

### Step 1：选择发票文件夹

| 用户操作 | 界面反应 | 说明 |
|---|---|---|
| 点击「选择文件夹」 | 调用 `showDirectoryPicker()` | 浏览器弹原生选择器 |
| 浏览器不支持 API | 弹错误对话框 | 「请使用 Chrome 或 Edge」 |
| 选完文件夹 | 列出所有 PDF/XML 文件 | 显示数量统计 |
| 点击「下一步」 | 进入 Step 2 自动识别 | 未选目录则按钮禁用 |

### Step 2：识别 + 审查

| 用户操作 | 界面反应 | 说明 |
|---|---|---|
| 进入 Step 2 | 自动开始识别，显示进度条 | 调用 DeepSeek API 串行处理 |
| 未配置 API Key | 自动弹设置弹窗 | 点关闭则识别中止 |
| 识别中点「暂停」 | 暂停，按钮变「继续」 | 已识别的保留 |
| 点击发票行 | 展开详情面板 | 展示备注、车次、出发地等 |
| 点击发票的"类别"列 | 弹出下拉菜单可改类别 | 改后该问题清单同步刷新 |
| 点击「手动添加」 | 弹窗：填写发票字段 | 用于扫描件无法识别时补录 |
| 点击「删除选中」 | 二次确认后删除（仅从列表移除） | 不删原文件 |
| 点击问题清单某条 | 高亮对应发票行 + 滚动到可见 | |
| 有问题但用户点「下一步」 | 弹确认框「仍有 N 个问题，是否继续？」 | 用户可强制继续 |

### Step 3：填写信息

| 用户操作 | 界面反应 | 说明 |
|---|---|---|
| 进入 Step 3 | 部门/出差人自动填入（从 localStorage） | 首次为空 |
| 修改部门/出差人 | 失焦时存回 localStorage | 自动持久化 |
| 修改予借旅费 | 实时重算补领/退还金额 | 联动显示 |
| 项目简写/事由为空 | 「下一步」按钮禁用 | 高亮提示 |

### Step 4：归档 + 生成

| 用户操作 | 界面反应 | 说明 |
|---|---|---|
| 点击「选择输出目录并执行」 | 调用 `showDirectoryPicker({mode:'readwrite'})` | 用户选目录 |
| 执行中 | 显示进度（创建子目录 → 复制文件 → 生成 Excel） | |
| 出错（无写权限等） | 友好提示 + 重试按钮 | |
| 完成 | 显示绿色"完成"+ 路径 + 下载文件名 | 可点击「再做一次」回 Step 1 |

## 五、风格细节

- 所有按钮带 8-12px 圆角
- 表格行 hover 背景浅蓝
- 错误用 `#F56C6C`（红），警告 `#E6A23C`（橙），成功 `#67C23A`（绿）
- 步骤条已完成步骤显示对勾 ✓
- 问题清单条目按严重度排序（错误 > 警告 > 提示）
